Expressions

\[ \log\det M[\phi]=\log\det(\mathbb{1}_{N_x}+\underbrace{F_k(N_t-1).F_k(N_t-2)\ldots F_k(0)}_{\mathrm{``sausage\ 1"}})\quad;\quad F_k(t)\equiv \underbrace{e^{\tilde\kappa}}_{\mathrm{dense}}. \underbrace{e^{i\phi_t(x)}}_{\mathrm{diagonal}} \quad;\quad \tilde\kappa=\kappa\frac{\beta}{N_t}\]

\[\partial_{\phi_t(x)} \log\det M[\phi]= \left\{f_k(t+1).f_k(t+2)\ldots f_k(N_t-1).[\mathbb{1}_{N_x}+\underbrace{f_k(0)\ldots f_k(N_t-1)}_{\mathrm{``sausage\ 2"}}]^{-1}.f_k(0)\ldots f_k(t) \right\}_{x,x} \] \[ f_k(t)=F_k^{-1}(k)=e^{-i\phi_t(x)}.e^{-\tilde\kappa}\]

Note: \([\mathrm{sausage\ 2}]^{-1}=\mathrm{sausage\ 1}\)

Stabilizing \(\log\det M\)

  • Express \(F_k(t)=e^{\tilde\kappa}.e^{i\phi_t}=U.\underbrace{D_{\tilde\kappa}}_{\mathrm{diagonal}}.\underbrace{V.e^{i\phi_t}}_{\equiv V(t)}\equiv U.D_{\tilde\kappa}.V(t)\)

    • Note that \(U.V=\mathbb{1}_{N_x}\) and \(V(t).V^\dagger (t)=\mathbb{1}_{N_x}\)

  • Initial SVD of sausage \[ F_k(N_t-1).F_k(N_t-2)\ldots F_k(0)=U.\underbrace{D_{\tilde\kappa}.V(N_t-1).U.D_{\tilde\kappa}}_{=u.d.v}.V(N_t-2)\ldots U.D_{\tilde\kappa}.V(0)\]

  • Recursively perform SVD1 on expressions of the form \(D.V(t).U.D =u.d.v\) until one arrives at \[ \mathbb{1}_{N_x}+u.d.v = u.(\underbrace{u^\dagger v^\dagger+d}_{q.r}).v \quad\quad (=\mathbb{1}_{N_x}+\mathrm{sausage})\]

  • Final expression for \(\log\det M\) \[ \log\det M = \log\det\left(u.q.r.v\right) =\log\det(u.q)+\log\det(v)+\sum_x\log r_{x,x}\]

  1. One can also do a different decomposition, like QR. For these notes I only assume SVD. Only slight changes would be required for a different decomposition.

Stabilizing \(\partial\log\det M\)

  • Key feature here is the construction of \([\mathbb{1}+f_k(0)\ldots f_k(N_t-1)]^{-1}\)

  • Express \(f_k(t)=e^{-i\phi_t}.e^{-\tilde\kappa}=\underbrace{e^{-i\phi_t}.U}_{\equiv U(t)}.\underbrace{D_{\tilde\kappa}}_{\mathrm{diagonal}}.V\equiv U(t).D_{\tilde\kappa}.V\)

  • As before, we construct the sausage via recursive decomposition \[ \mathbb{1}+f_k(0)\ldots f_k(N_t-1)=\mathbb{1}+u.d.v=u.(\underbrace{u^\dagger v^\dagger+d}_{q.r}).v =u.q.r.v\]

  • Then we have \[ [\mathbb{1}+f_k(0)\ldots f_k(N_t-1)]^{-1}=v^\dagger.r^{-1}.q^\dagger.u^\dagger \]

  • Though there is an inverse to calculate, \(r^{-1}\), this matrix is triangular and so this should not be that bad

Strategy for calculating \(\partial_{\phi_t}\log\det M\)

  • Assume we can calculate \(\mathcal{N}_k\equiv[f_k(0)\ldots f_k(N_t-1)].[\mathbb{1}+f_k(0)\ldots f_k(N_t-1)]^{-1}\)

    \(=\dot\pi(N_t-1)\)

  • Then \[ \begin{align} \dot\pi(0)&=f_k(0)^{-1}.\mathcal{N}_k.f_k(0) = F_k(0).\mathcal{N}_k.f_k(0)\\ \dot\pi(1)&=f_k(1)^{-1}.\dot\pi(0).f_k(1)=F_k(1).\dot\pi(0).f_k(1)\\ \vdots\\ \dot\pi(t)&=f_k(t)^{-1}.\dot\pi(t-1).f_k(t)=F_k(t).\dot\pi(t-1).f_k(t)\\ \vdots\\ \dot\pi(N_t-2)&=f_k(n_t-2)^{-1}.\dot\pi(N_t-3).f_k(N_t-2)=F_k(N_t-2).\dot\pi(N_t-3).f_k(N_t-2) \end{align} \]

The calculation of \(\dot\pi(t)\) can be done iteratively, since it only depends on the previous \(\dot\pi(t-1)\). Furthermore, I suspect that it is very stable (i.e. doesn’t need any decompositions) since we are always multiplying matrices with matrix elements of \(\mathcal{O}(1)\).

But this assumes that we have calculated \(\mathcal{N}_k\) accurately!!!

Note, we do have a stable way of calculating \(\mathcal{N}_k\). However(!!!), the iterative method proposed above is not stable, even with decompositions 😠

My one idea that “works”

  • I “chop” the unitary matrix \(v.u\)

    • Consider relative size of off-diagonal matrix element \(m_{ij}\) to diagonal matrix element \(m_{ii}\): \(\frac{m_{ij}}{m_{ii}}\)

Another strategy for calculating forces

  • Johann points out another strategy for calculating forces that should be more stable than that proposed in Section 4

  • Given1 \[ \dot\pi(N_t-1)=\left[\mathbb{1}+F_k(N_t-1)\ldots F_k(0)\right]^{-1}\equiv\left[\mathbb{1}+\mathcal{F}(N_t-1)\right]^{-1} \] it is easy to show that

    \[ \begin{align} \dot\pi(0)=F_k(0).\dot\pi(N_t-1).f_k(0)=\left[\mathbb{1}+F_k(0)F_k(N_t-1)\ldots F_k(0)f_k(0)\right]^{-1} &=\left[\mathbb{1}+F_k(0).\mathcal{F}(N_t-1).f_k(0)\right]^{-1}\\ &\equiv \left[\mathbb{1}+\mathcal{F}(0)\right]^{-1} \end{align} \]

  • This is generalizable \[ \dot\pi(t)=\left[\mathbb{1}+\mathcal{F}(t)\right]^{-1} \] where

    \[ \mathcal{F}(t)=F_k(t).\mathcal{F}(t-1).f_k(t) = \overbrace{F_k(t).F_k(t-1)\ldots F_k(0).F_k(N_t-1).F_k(N_t-2)\ldots F_k(t+1)}^{N_t\ \mathrm{terms}} \]

  • The terms \(\mathcal{F}(t)\) can be solved iteratively (though it remains to be seen if this is stable)

  1. Remember that \(F_k(t)=f^{-1}_k(t)\)!

Speeding up the force calculation

  • Unfortunately none of the recursive schemes proposed in Section 4 and Section 7 are stable

  • But as suggested by Johann and implemented earlier by Finn, the prefix/suffix scheme speeds things up considerably

  • One calculates

    • all possible ‘prefixes’ \(\Pi(t) = F_k(t).F_k(t-1)\ldots F_k(0)\)
    • all possible ‘suffixes’ \(\Sigma(t) = F_k(N_t-1).F_k(N_t-2)\ldots F_k(t)\)
    • these calculations can be done recursively and thus fast, and requires \(\mathcal{O}(2N_t V^2)\) memory (which is rougly 2 times more), but this is not an issue

  • The force at timeslice \(t\) is simply \(\dot\pi(t)=\left[1+\Pi(t).\Sigma(t+1)\right]^{-1}\)

    • this calculation scales as \(\mathcal{O}(N_t V^3)\)
    • every aspect of this calculation is stable!
